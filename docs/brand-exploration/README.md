# MykTech() identity exploration

`identity-directions-v2.png` is the image-generated concept proposal shown to the user on November 4, 2026. The user selected the middle direction, **Ignition — keycap, M/T, gold spark**. The other directions were not selected.

The selected idea was redrawn as editable vector geometry, with an outlined DM Serif Display Italic wordmark, adjusted spacing and a custom k terminal. The production artwork lives in `public/brand/myktech/`; its source is `scripts/build-brand.mjs`. It is not a raster crop or an automated trace of this proposal.

Myk is the leader's name. The keycap, M/T and spark communicate the intended design idea: turning an idea into working software. They do not claim a hidden origin for the name.

The initially rejected geometric split-M concept has been replaced throughout the generated assets and website identity.
