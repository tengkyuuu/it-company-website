## 4. Answers we must not guess (Services FAQ + Contact)

1. How long does a typical website / app / system take?
2. How does pricing work? (Not figures: e.g. "fixed quote after a scoping call".)
3. Who owns the code and design files when the project ends?
4. How do you work with clients abroad? (Time zones, meetings, invoicing currency.)
5. What happens after launch? (Support, maintenance, retainers.)
6. Can you take over an existing system someone else built?
7. **Is "we reply within one business day" true?** It's on the Contact page now.
8. What actually happens after someone sends the form? (Reply → call → proposal?)
